# zhu-weizx-notes

Game developer @Discord

处理日常小任务的工具

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/zhu-weizx-notes.git
cd zhu-weizx-notes
npm install
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。
